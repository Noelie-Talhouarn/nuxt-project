# Button.vue — Utilisation de l’IA

## Contexte
Création d’un composant bouton réutilisable pour le projet.
L’objectif était d’avoir plusieurs variantes tout en gardant
un composant simple et maintenable.

## Aide de l’IA
L’IA a été utilisée pour :
- réfléchir à la structure générale du composant
- organiser les classes CSS selon la méthode ABEM

prompt utilisé :
"Peux-tu proposer une structure de composant Button en Nuxt
avec plusieurs variantes et un style clair ?"

## Travail personnel
- Adaptation du code à la charte graphique du projet
- Simplification de la logique proposée
- Ajustement des styles et des interactions selon les besoins réels
