# Header.vue — Utilisation de l’IA

## Contexte
Composant Header responsive développé dans un projet Nuxt 3.
Il gère la navigation principale, l’authentification
et le menu burger pour la version mobile.

## Aide de l’IA
L’IA a été utilisée comme aide ponctuelle pour :
- réfléchir à la structure d’un composant dans Nuxt 3
- comprendre la logique d’un menu burger responsive
- clarifier l’organisation des classes CSS (méthode ABEM)

prompt utilisé :
"Comment structurer un menu burger responsive dans un composant Nuxt 3 ?"
"Mon style css est-il bien fais selon la methode ABEM ?"


## Travail personnel
- Intégration du composant dans l’architecture Nuxt
- Gestion de l’état du menu avec la Composition API
- Adaptation du code aux contraintes du projet
- Corrections, tests et ajustements manuels
