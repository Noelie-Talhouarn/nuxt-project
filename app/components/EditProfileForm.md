# EditProfileForm.vue — Utilisation de l’IA

## Contexte
Ce composant a été développé dans un projet **Nuxt 3**.
Il permet à un utilisateur connecté de modifier ses informations
de profil (nom, prénom, nom d’utilisateur, email).

Le formulaire gère :
- l’affichage des données existantes de l’utilisateur
- la modification des champs
- l’envoi des données vers l’API
- l’affichage des messages de succès ou d’erreur

---

## Aide de l’IA
L’IA a été utilisée comme **outil d’assistance ponctuelle** pour :
- clarifier la structure d’un formulaire en Vue 3 / Nuxt 3
- comprendre la gestion des `props` et des `emit`
- vérifier la logique d’appel à l’API avec authentification
- organiser les classes CSS selon la méthode ABEM

prompt utilisé :
"Comment organiser un formulaire de modification de profil
dans un projet Nuxt 3 en utilisant la Composition API ?"
"Mon style css est-il bien fais selon la methode ABEM ?"


---
## Travail personnel
- Intégration du composant dans l’architecture Nuxt
- Initialisation manuelle du formulaire à partir des données utilisateur
- Gestion des événements (`close`, `updated`)
- Connexion à l’API sécurisée via token
- Gestion des messages de succès et d’erreur
- Ajustement du design et des styles selon la charte graphique
