# MyFooter.vue — Utilisation de l’IA

## Contexte
Ce composant a été développé dans un projet **Nuxt 3**.
Il correspond au pied de page du site et est affiché sur l’ensemble
des pages de l’application.

Le footer contient :
- le logo du site provenant du CMS Sanity
- une navigation provenant du CMS Sanity
- des liens vers les réseaux sociaux
- une mention de copyright

---

## Aide de l’IA
L’IA a été utilisée comme **outil d’assistance ponctuelle** pour :
- réfléchir à la structure d’un composant Footer réutilisable
- organiser les éléments de navigation et les icônes sociales
- vérifier la cohérence des classes CSS selon la méthode ABEM

prompt utilisé :
"Comment structurer un composant Footer en Nuxt 3
avec navigation, logo et liens vers les réseaux sociaux ?"
"Mon style css est-il bien fais selon la methode ABEM ?"


---

## Travail personnel
- Intégration des données provenant du CMS Sanity (logo, navigation)
- Mise en place de la navigation avec `NuxtLink`
- Import et utilisation des composants d’icônes SVG
- Organisation du layout du footer (navigation, réseaux sociaux, texte)
- Stylisation complète selon la charte graphique du projet
- Ajustements visuels et tests d’affichage responsive
