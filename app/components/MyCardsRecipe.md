# MyCardsRecipe.vue — Utilisation de l’IA

## Contexte
Ce composant a été développé dans un projet **Nuxt 3**.
Il représente une carte de recette affichée dans différentes listes
(tableau de bord utilisateur, page d'accueil).

La carte affiche :
- l’image de la recette
- le titre
- une description courte
- des informations associées (cuisine, régime, objectif)
- un lien vers la page de détail de la recette

---

## Aide de l’IA
L’IA a été utilisée comme **outil d’assistance ponctuelle** pour :
- réfléchir à la structure d’un composant de carte réutilisable
- organiser l’affichage des informations d’une recette
- vérifier la cohérence entre les données reçues et leur affichage
- organiser les classes CSS selon la méthode ABEM


Exemple de prompt utilisé :
"Comment structurer un composant de carte en Nuxt 3
pour afficher une recette dans une liste ?"
"Mon style css est-il bien fais selon la methode ABEM ?"

## Travail personnel
- Création du composant et définition des `props`
- Intégration du composant dans l’architecture Nuxt
- Liaison des données dynamiques provenant de l’API
