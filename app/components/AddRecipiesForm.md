# AddRecipesForm.vue — Utilisation de l’IA

## Contexte
Formulaire développé dans un projet Nuxt 3 permettant
à un utilisateur connecté de créer une recette.
Le composant gère la saisie, la validation et l’envoi des données vers l’API.

## Aide de l’IA
L’IA a été utilisée pour :
- réfléchir à la structure du formulaire
- clarifier la gestion des données avec `ref`
- comprendre certaines erreurs rencontrées lors du développement
- organiser les classes CSS selon la méthode ABEM

prompt utilisé :
"Comment organiser un formulaire complexe en Vue 3 / Nuxt 3
avec la Composition API ?"
"Mon style css est-il bien fais selon la methode ABEM ?"

## Travail personnel
- Implémentation complète du formulaire
- Connexion à l’API du projet
- Ajustement du style et de l’expérience utilisateur
